# 九人桌

一个供同学私下联机的轻量德州扑克游戏。最多 9 人，房间和筹码保存在服务器内存中，不涉及真钱、充值或提现。

## 启动

```bash
npm install
npm run dev
```

本机打开 `http://localhost:4173`。

同一 Wi-Fi 下的同学可打开 `http://你的局域网IP:4173`。可用下面的命令查看常见 Wi-Fi 接口地址：

```bash
ipconfig getifaddr en0
```

第一次接受外部连接时，macOS 可能会询问是否允许 Node 接收网络连接。

## 验证

```bash
npm test
npm run build
```

## 当前规则

- 2–9 人，初始筹码 2,000
- 小盲/大盲 10/20
- 支持弃牌、过牌、跟注、加注和 All-in
- 支持主池、边池、平分底池和摊牌亮牌
- 刷新页面可使用浏览器保存的身份重连

服务器停止或重启后，当前房间会清空。
